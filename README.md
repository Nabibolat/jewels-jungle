# Jewels Jungle — Три в ряд

Статическая версия игры для GitHub Pages и Telegram Mini Apps. Интерфейс на русском языке.

## Запуск локально

Откройте `index.html` в браузере или запустите простой локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Публикация на GitHub Pages

1. Откройте Settings → Pages в репозитории.
2. В разделе Build and deployment выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/(root)**.
4. Нажмите Save и дождитесь публикации.
5. Адрес сайта будет иметь вид https://nabibolat.github.io/jewels-jungle/.

## Подключение к Telegram

1. Создайте бота через @BotFather, если ещё не сделали этого.
2. В настройках бота задайте Mini App / Web App URL, полученный после публикации GitHub Pages.
3. Для кнопки запуска используйте HTTPS URL сайта.

## Что входит и чего пока нет

- Рабочее поле 8×8, обмен соседних камней, совпадения от 3, начисление очков, ходы и локальный рекорд.
- Telegram Web App SDK подключается, имя игрока берётся из доступного Telegram-контекста.
- Рекорд хранится в localStorage на устройстве пользователя.

Это frontend-прототип. Общий рейтинг, синхронизация прогресса между устройствами, реферальные награды, серверная проверка Telegram initData и рекламные вознаграждения пока не реализованы. Локальный рекорд нельзя считать защищённым от подмены.


## Аналитика и закрытая панель владельца

В репозитории есть заготовка backend на FastAPI и страница `admin.html`. Статистика собирается только после развертывания backend и подключения его адреса в `config.js`.

1. Разверните `backend/` на хостинге с постоянным диском/томом для SQLite.
2. Задайте переменные окружения: `BOT_TOKEN` (токен Telegram-бота), `OWNER_TELEGRAM_ID` (Telegram ID владельца) и при необходимости `CORS_ORIGINS` (адрес GitHub Pages).
3. Укажите HTTPS-адрес backend в `config.js` как `window.JJ_API_BASE`.
4. В Telegram откройте `admin.html` как отдельную Mini App или добавьте защищённую ссылку в меню владельца.

Backend проверяет подпись Telegram `initData` и сверяет ID владельца на сервере. Не помещайте BOT_TOKEN или OWNER_TELEGRAM_ID в HTML/JavaScript. Пока backend не развернут и клиентская отправка событий не подключена, панель не показывает реальные данные. Онлайн означает активность за последние 5 минут и обновляется при heartbeat.
